## ✦ Sobre mim

Oi! Eu sou a **Kauany Neves**, estudante de **Desenvolvimento de Sistemas**.

Atualmente, venho desenvolvendo meus conhecimentos principalmente na área de **desenvolvimento web**, trabalhando com tecnologias como PHP, Laravel, JavaScript, HTML, CSS e MySQL.

Grande parte do que estou aprendendo vem de projetos acadêmicos e experiências práticas, onde posso participar de diferentes etapas do desenvolvimento — desde a criação da interface e organização do projeto até a implementação das funcionalidades e do banco de dados.

Ainda estou construindo minha trajetória na área, mas gosto de aprender na prática, experimentar novas ideias e transformar projetos em algo que realmente funcione.

<br>

> `aprendendo → desenvolvendo → melhorando`

### 🎈 TCC — Sistema para Buffet Infantil

**Status:** `EM DESENVOLVIMENTO`

Projeto acadêmico desenvolvido em equipe durante o curso de Desenvolvimento de Sistemas.

A aplicação está sendo criada para um **buffet infantil**, com o objetivo de centralizar informações e recursos que auxiliem na apresentação dos serviços e no contato entre o buffet e seus clientes.

O desenvolvimento envolve diferentes etapas, incluindo planejamento, criação das interfaces, desenvolvimento das funcionalidades, estruturação do banco de dados e organização do projeto.

**Tecnologias**
